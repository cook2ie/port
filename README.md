# 📺 Portfolio Website (Personal Project)

개인 포트폴리오 웹사이트를 구현한 프로젝트입니다.  
UI/UX 설계부터 퍼블리싱까지 직접 작업했으며,  
프로젝트 중심의 구조와 스크롤 인터랙션 구성에 집중했습니다.

---

## 🔗 Live Site

👉 [포트폴리오 바로가기](https://cook2ie.github.io/port/)

## 🧩 Overview

- 반응형 웹 구현 (Desktop / Tablet / Mobile)
- 프로젝트 중심의 정보 구조 설계
- 스크롤 기반 인터랙션을 활용한 메인 화면 구성
- UI/UX 설계부터 퍼블리싱까지 직접 작업

---

## 🛠 Tech Stack

- HTML / CSS / JavaScript
- jQuery
- GSAP / ScrollTrigger / Swiper

---

## 👨‍💻 Key Points

- GSAP / ScrollTrigger를 활용한 스크롤 애니메이션 구현
- 프로젝트 모달 UI 구성 및 상태 제어
- 사용자 흐름을 고려한 DOM 구조 설계
- 반응형 환경에서도 일관된 화면 구성을 위한 레이아웃 설계
- 컴포넌트 단위 구조 분리를 통해 유지보수성 고려

## 💡 What I Learned

- 포트폴리오 사이트는 단순히 작업물을 나열하는 것이 아니라, 사용자가 자연스럽게 흐름을 따라가며 프로젝트를 이해할 수 있도록 구조를 설계하는 것이 중요하다는 점을 배웠습니다.
- 인터랙션 요소를 추가할 때도 시각적인 효과 자체보다, 전체 화면 흐름과 사용성 안에서 자연스럽게 작동하도록 구성하는 것이 더 중요하다는 점을 경험했습니다.
- UI/UX와 퍼블리싱을 함께 다루는 작업에서는 디자인 완성도와 코드 구조의 균형을 함께 고려해야 한다는 점을 다시 느꼈습니다.
